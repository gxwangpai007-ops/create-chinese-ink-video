# 连续流体墨场显影

当用户要求“墨在水里散开”“喷气、烟雾或墨流经过后画面形成”“不要圆形烟团”“显影速度要缓慢均匀”时使用本路线。

## 视觉目标

连续流体墨场必须同时出现：

- 浓墨核心、半透明墨体和较深湿边
- 连续卷曲、回流、分叉与细丝，而非沿路径堆叠圆形粒子
- 旧墨离开喷口后继续扩散，不随主体整体移动
- 同一流体场驱动可见墨色和画面显影
- 湿墨先形成体块，干笔或线描随后锁定主体结构
- 扩散在结尾减速并停住，不在最后一帧硬补齐

## 因果结构

```text
运动主体或墨源
→ 注入速度、压力与颜料密度
→ 连续流体平流、压力投影和涡量约束
→ 可见墨层 fluid-density
→ 累积显影母版 fluid-exposure
→ 环境洗染
→ 物体湿墨体块
→ 人物衣服与肩部
→ 面部和关键结构干笔锁定
→ 浮墨减弱并停留
```

不得分别生成一个烟雾动画和一个独立显影遮罩。两者必须来自同一密度场，否则因果关系会漂移。

## 确定性实现

优先运行：

```bash
python <skill-dir>/scripts/render_fluid_ink_matte.py \
  --output <project>/assets/fluid-density.mp4 \
  --exposure-output <project>/assets/fluid-exposure.mp4 \
  --duration 6.4 \
  --start 0.78,0.72 \
  --end 0.74,0.18
```

脚本输出：

- `fluid-density.mp4`：随时间流动的可见墨层。
- `fluid-exposure.mp4`：颜料实际经过后积累的显影母版。
- 同名 `.json`：模拟、时长、路径与帧率参数。

输入坐标为 0–1 的画幅归一化坐标。路径默认近似匀速；需要曲线路径时，在项目渲染器中以分段线性路径替换，不要重新引入慢—快—慢的默认缓动。

## 推荐起始参数

| 参数 | 推荐值 | 作用 |
|---|---:|---|
| 内部帧率 | 48 fps | 捕获连续流体变化 |
| 输出帧率 | 24 fps | 两帧时域混合后输出 |
| 模拟宽度 | 150 | 竖版低清动态样片 |
| 时长 | 5.5–8 s | 给扩散、主体锁定和停留留出时间 |
| 流体推进 | 0.55–0.80 | 越低越缓慢 |
| 曝光积累 | 0.045–0.065 | 控制画面形成速度 |
| 浮墨退场 | 最后 15–20% | 只减弱浮墨，不抹掉已形成主体 |

如果正常播放时速度忽快忽慢：

1. 检查墨源路径是否使用强 ease-in-out。
2. 检查涡旋方向是否按整数时间硬切换。
3. 把离散方向切换改为连续正弦相位。
4. 降低推进力并延长镜头，不要只给现有动画做整体慢放。
5. 重新运行帧间变化扫描，比较修订前后的峰值分布。

## 分层合成

按以下职责使用两路母版：

```text
paper
environment × soft(fluid-exposure)
object × fluid-exposure
character body × delayed soft(fluid-exposure)
face / key structure × later dry-lock
visible wet ink × fluid-density
moving source
```

人物面部不得先于肩部和衣服形成。大面积人物可使用较宽的曝光场，但必须保持“流体先抵达、结构后锁定”的时间顺序。

浮墨可以在结尾下降约 40–65%，让已经形成的主体露出；不得切换到另一张完成静帧。

## 动态 QA

正常速度播放后检查：

- 墨体是否连续，而不是一串圆团或一根软管
- 卷曲速度是否均匀，是否存在突然换向
- 可见墨层与主体显影是否保持空间因果
- 人物是否出现脸形白洞、硬轮廓或整层跳出
- 最终构图是否留下有意留白

用 `analyze_frame_delta.py` 比较当前版本与自身基线。连续流体可以产生较高变化量，但局部翻卷不应演变为整块矩形显影峰值。
