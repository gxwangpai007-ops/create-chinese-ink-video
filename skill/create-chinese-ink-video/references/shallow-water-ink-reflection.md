# 瓶底浅水墨场与倒影联动

用于产品立于湿润接触面、瓶底水墨波纹向外扩散，并要求水中倒影随波纹自然晃动的镜头。

## 因果结构

```text
瓶底接触点
→ 扁平椭圆浅水高度场
→ 同一相位上的墨色波峰、湿边和纤维缺口
→ 高度场梯度折射接触面下方的真实倒影
→ 产品实体最后锁定合成
```

不得把扩散特效叠在静态墨迹上，也不得用独立正弦位移晃动倒影。可见波纹与倒影折射必须读取同一高度场。

## 输入

- 含产品与原始倒影的稳定底板。
- 灰度产品保护遮罩：高值保护实体，中值标记可折射倒影。
- 产品与接触面的准确接触点。
- 接触面透视决定的椭圆半径；不要先生成圆形波纹再纵向压扁。

## 确定性脚本

```bash
python <skill-dir>/scripts/render_shallow_water_ink_reflection.py \
  --plate <product-plate.png> \
  --product-mask <product-protection-mask.png> \
  --contact 0.5,0.8385 \
  --radius 0.3333,0.0411 \
  --output <project>/preview/product-ink-ripple-v01.mp4 \
  --manifest <project>/preview/product-ink-ripple-v01.json
```

坐标与半径均为画幅归一化值。默认以 48 fps 计算并两帧混合输出 24 fps。

## 推荐参数

| 参数 | 默认值 | 作用 |
|---|---:|---|
| `period` | 1.72 s | 波纹频率；增大则更慢、更低频 |
| `wavelength` | 0.225 | 相邻波峰间距 |
| `front-speed` | 0.245 | 外扩速度 |
| `radius` | `0.3333,0.0411` | 地面透视下的横纵半径 |
| `reflection-displacement` | `5.4,11.6` px | 倒影横纵折射幅度 |

用户要求“更慢、频率更低、范围更大”时，优先增大 `period` 与 `radius`，小幅降低 `front-speed`；不要只给整段视频做慢放。

## 合成顺序

```text
稳定底板
→ 倒影折射
→ 同场可见墨峰与沉积
→ 环境与植物层
→ 产品实体保护层
```

产品实体不得随波场扭曲。倒影必须在接触线以下渐入折射，接触线与瓶底保持锚定。

## QA

正常速度播放并检查：

- 波纹中心是否位于真实瓶底，而非瓶后或瓶身中部。
- 波纹是否为接触面透视一致的扁平椭圆。
- 墨峰是否连续流动，而非静态墨迹上的扩散滤镜。
- 倒影是否有轻微横纵折射，同时保持瓶底锚定。
- 产品实体、标签和轮廓是否稳定。
- 是否出现矩形职责框、硬遮罩边界或整块突然显影。

抽查第一圈波峰、最大扩散和稳定完成态；再运行 `analyze_frame_delta.py` 定位异常峰值。
