# 纤维状墨团生长

当人物、车辆、建筑或产品需要“随机墨团逐渐拼出主体”“带缺口的 C 形墨迹生长”“纤维边缘显影”，而连续流体仍应承担环境、喷气或大范围湿墨时，使用本路线。

## 职责边界

将两种材料行为分开：

```text
continuous fluid
→ 环境、喷气、空间湿墨与到达时机

fibrous blooms
→ 主体局部显影前缘
→ 多个随机缺口墨团错时覆盖
→ 干笔结构最终锁形
```

纤维墨团不得替代已经批准的连续流体喷气。主体墨团必须由流体到达场或叙事触发器门控，不能与背景烟雾各自独立播放。

## 形成语法

单个墨团包含：

- 深色核心或半透明湿墨体
- 带宣纸纤维扰动的边缘
- 临时的 C 形／弧形缺口
- 不完全规则的半径、偏心率与角速度
- 随生长逐渐闭合的缺口
- 通过后保留的累积显影母版

不要只生成一个居中的规则 C。默认用 3–7 个墨团叠加，并改变：

- 中心位置
- 起始时间
- 横纵半径
- 缺口方向与宽度
- 边缘噪声相位
- 生长时长

## 主体顺序

车辆或横向产品：

```text
局部尾部／底部墨团
→ 车身或产品主体的错时墨团
→ 轮廓与关键高光干笔锁定
```

人物：

```text
衣服与下部体块
→ 肩部和外轮廓
→ 颈部
→ 面部湿墨
→ 五官和关键结构干笔锁定
```

面部不得先于衣服和肩部完成，也不得以脸形白洞等待填充。

## 确定性母版

优先运行：

```bash
python <skill-dir>/scripts/render_fibrous_ink_bloom.py \
  --output <project>/assets/fibrous-density.mp4 \
  --exposure-output <project>/assets/fibrous-exposure.mp4 \
  --mask <project>/assets/subject-mask.png \
  --duration 4.8
```

脚本输出：

- `fibrous-density.mp4`：当前正在生长的 C 形／缺口纤维前缘。
- `fibrous-exposure.mp4`：墨团经过后累积保留的主体显影母版。
- 同名 `.json`：种子、墨团参数、帧率与分辨率。

使用 `--blooms-json` 传入自定义墨团数组。坐标和半径均使用 0–1 画幅归一化值。

## 推荐起始参数

| 参数 | 车辆／产品 | 人物 |
|---|---:|---:|
| 墨团数量 | 3–5 | 5–7 |
| 单团生长时长 | 1.3–2.0 s | 1.4–2.1 s |
| 相邻起始间隔 | 0.25–0.55 s | 0.30–0.60 s |
| 临时缺口强度 | 0.70–0.90 | 0.65–0.85 |
| 缺口闭合起点 | 55–65% | 58–70% |
| 纤维前缘可见度 | 0.30–0.50 | 0.25–0.45 |
| 最终干笔锁形 | 后 20–30% | 后 22–35% |

## 合成

```text
paper
environment × fluid-exposure
subject × fibrous-exposure × causal-arrival
fibrous-density × causal-arrival
visible wet ink × fluid-density
late dry-lock
moving source
```

`fibrous-density` 可在结尾减弱，但 `fibrous-exposure` 必须保留。多个墨团完成后使用同一主体母版进行干笔锁形，不得切换到另一张静帧。

## QA

正常速度播放并检查：

- 墨团是否大小、方向和节奏不同
- 是否更像随机卷曲墨云，而非规则字母或同心圆
- 主体是否分区逐步形成，而非整层淡入
- 缺口是否自然闭合，没有永久白洞
- 人物衣服和肩部是否先于面部
- 纤维前缘是否局限于形成区域，没有覆盖或替换主要喷气
- 最终主体是否稳定且结构清楚

如果出现大量圆章状斑点，减少墨团数量、增大半径差异并拉开起始时间。如果 C 形过于字面化，随机旋转缺口方向、增加偏心率，并让多个墨团互相遮盖。
